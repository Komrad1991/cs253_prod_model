# ============================================================================
#  Deadlock: контр-предметы — база знаний продукционной модели
#
#  Предметная область: герои Deadlock, предметы и контр-предметы.
#  Цепочка вывода: герой -> угроза -> наш контр-предмет -> предмет врага
#  в ответ -> второй контр-предмет.
#  Формат: обычный текстовый файл (.txt); генератор — tools/gen_kb.py.
#
#  Слои вывода: 0 состав -> 1 угрозы -> 2 потребности -> 3 кандидаты
#               -> 4 шортлист -> 5 выбор -> 6 предмет врага в ответ
#               -> 7 его угроза -> 8 вторая потребность -> 9 второй контр
# ============================================================================
