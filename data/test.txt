#  Формат — простой, пропозициональный:
#    ФАКТЫ:    имя_факта - Отображаемое имя

#    ЦЕЛИ:     имя_цели
#
#  Что проверить в приложении:
#   1. Прямой вывод: из our_item_* и hero_tag_* выводятся uncovered_*.
#   2. Обратный вывод, цель uncovered_Curse_MoKrill_hard_cc — доказана.
#   3. Обратный вывод, цель cycle_a_MetalSkin — упирается в цикл
#      cycle_a_MetalSkin -> cycle_b_MetalSkin -> cycle_a_MetalSkin:
#      ветвь отбрасывается с пометкой «цикл предотвращён», но другой
#      продукции у цели нет, поэтому она остаётся недоказанной.
# ============================================================================
