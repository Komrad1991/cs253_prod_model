# ============================================================================
#  Deadlock: контр-предметы — база знаний продукционной модели
#
#  Предметная область: герои Deadlock, предметы и контр-предметы.
#  Цепочка вывода: герой -> угроза -> потребность -> кандидат -> выбор
#  -> предмет врага в ответ -> его угроза -> вторая потребность
#  -> второй контр-предмет.
#
#  Формат — простой, без аргументов и коэффициентов уверенности:
#    ИМЯ: / ОПИСАНИЕ:            — заголовок базы;
#    ФАКТЫ:   по одному факту в строке (можно «id - Название»);
#    ПРАВИЛА: посылки через запятую, стрелка ->, заключения через запятую;
#             отрицание — префикс «not » или «не »;
#    ЦЕЛИ:    по одной цели в строке.
#  Составные предикаты вида hero(Haze) записаны слитно: hero_Haze.
#
#  Слои вывода: 0 состав -> 1 угрозы -> 2 потребности -> 3 кандидаты
#               -> 4 выбор -> 5 рекомендация -> 6 предмет врага в ответ
#               -> 7 его угроза -> 8 вторая потребность -> 9 второй контр
# ============================================================================
