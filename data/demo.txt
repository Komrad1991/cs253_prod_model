# ============================================================================
#  Демонстрационная база знаний ProdModel — "Deadlock Demo"
#
#  Формат — простой, пропозициональный (без аргументов и коэффициентов):
#    ФАКТЫ:    имя_факта - Отображаемое имя
#    ПРАВИЛА:  условие1, условие2, not условие3 -> заключение1, заключение2
#    ЦЕЛИ:     имя_цели
#  Всё, что в богатом формате было предикатом с аргументами, здесь
#  «сплющено» в одно имя: hero_tag(Haze, bullet_dps) -> hero_tag_Haze_bullet_dps.
#
#  Что и как проверить в приложении:
#
#   1. ПРЯМОЙ ВЫВОД (переключатель «Прямой вывод»)
#      ▶ Играть / ⏭ Шаг / ⏩ Всё сразу — цепочки
#      hero_tag_* -> threat_* -> pick_* -> recommended_*
#      Граф слева показывает слои вывода, вкладка «Факты» — источник факта.
#
#   2. ОТРИЦАНИЕ (not)
#      Правило threat_cc, not escape_threat -> threat_pure_cc срабатывает,
#      только если escape_threat не выведен. В этой базе Lash с тегом escape
#      присутствует, поэтому escape_threat выводится и threat_pure_cc НЕ
#      появляется. Уберите строку hero_tag_Lash_escape из ФАКТОВ — появится.
#
#   3. ОБРАТНЫЙ ВЫВОД, НЕСКОЛЬКО РЕШЕНИЙ
#      Переключатель «Обратный вывод», цель pick_MetalSkin_anti_bullet
#      (или любую другую pick_*) → «▶ Играть». Клик по строке результата
#      строит дерево доказательства справа.
#
#   4. ЦИКЛ В ОБРАТНОМ ВЫВОДЕ (главное демо!)
#      Цель cycle_a. Прямой вывод её не получает (факта cycle_b нет),
#      а обратный уходит в цикл cycle_a -> cycle_b -> cycle_a: ветвь
#      помечается «цикл предотвращён», красным чипом в дереве справа
#      видно, где именно поиск замкнулся. Альтернативной продукции у
#      cycle_a нет, поэтому цель честно остаётся недоказанной.
#      Случай «цикл предотвращён, а ответ всё равно получен» — в основной
#      базе deadlock_kb.txt, цель i_answers_Knockdown.
#
#   5. ОБРАТНЫЙ ЗАПРОС «предмет -> герои»
#      Цель uncovered_MetalSkin_Haze_escape: MetalSkin не покрывает escape,
#      поэтому герой остаётся опасным. Для bullet_dps правило не срабатывает —
#      MetalSkin этот тег покрывает (covers_MetalSkin_bullet_dps).
# ============================================================================

# ============================================================================
# Рекомендации предметов
# ============================================================================

threat_bullet_dps -> pick_MetalSkin_anti_bullet      # MetalSkin — универсальный ответ на пулевой урон
threat_cc -> pick_DebuffRemover_anti_cc              # DebuffRemover снимает контроль
threat_cc -> pick_Knockdown_anti_cc                  # Knockdown полезен против escape-целей
threat_spirit_burst -> pick_Curse_anti_spirit        # Curse блокирует спиритуальные ульты
threat_bullet_dps, threat_cc -> pick_ReturnFire_anti_bullet  # ReturnFire отвечает пулями, но уступает MetalSkin

# ============================================================================
# Вторичный контр-предмет
# ============================================================================

threat_spirit_burst -> second_pick_SilenceGlyph_anti_spirit  # SilenceGlyph — второй ответ на спиритуальные угрозы
threat_cc, escape_threat -> second_pick_Knockdown_anti_escape # Knockdown сбивает побег

# ============================================================================
# Демонстрация циклов (для обратного вывода)
# Цель cycle_a не выводится прямым выводом: факта cycle_b нет.
# Обратный вывод пробует cycle_b -> cycle_a, затем cycle_a -> cycle_b
# и возвращается в уже доказываемую цель — фиксируется цикл.
# ============================================================================

cycle_b -> cycle_a                                   # цикл: cycle_a требует cycle_b
cycle_a -> cycle_b                                   # цикл: cycle_b требует cycle_a
threat_spirit_burst -> recommended_Curse             # recommended_Curse через реальную угрозу spirit_burst

# ============================================================================
# Рекомендация — любой подтверждённый pick
# ============================================================================

pick_MetalSkin_anti_bullet -> recommended_MetalSkin
pick_DebuffRemover_anti_cc -> recommended_DebuffRemover
pick_Knockdown_anti_cc -> recommended_Knockdown
pick_Curse_anti_spirit -> recommended_Curse
